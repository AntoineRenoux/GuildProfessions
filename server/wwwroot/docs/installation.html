Installer GuildkeepInstalling Guildkeep

L'admin du serveur Discord crée la guilde en deux minutes, puis chaque joueur installe le pack de sa guilde. Ensuite, quelques réglages en jeu et sur Discord.The Discord server admin creates the guild in two minutes, then each player installs their guild's pack. Then a few settings in game and on Discord.

#Admin : créer la guilde avec /gkeep-setupAdmin: create the guild with /gkeep-setup

Admin « Gérer le serveur »Admin (“Manage Server”)

Il faut le droit Discord « Gérer le serveur ». La commande /gkeep-setup/gkeep-setup n'est d'ailleurs visible que par ceux qui l'ont. Une guilde Guildkeep correspond à un serveur Discord.You need the Discord "Manage Server" permission; only people who have it even see /gkeep-setup/gkeep-setup. One Guildkeep guild matches one Discord server.

DiscordTutoriel : installer Guildkeep sur ton serveurTutorial: set Guildkeep up on your server

  1. Sur l'accueil du site, clique Ajouter à DiscordAdd to Discord et choisis ton serveur. Le bot demande d'envoyer des messages, d'intégrer des liens, de joindre des fichiers et de gérer les pseudos (ce dernier droit ne sert que si tu actives le renommage).On the site's home page, click Ajouter à DiscordAdd to Discord and pick your server. The bot asks to send messages, embed links, attach files and manage nicknames (the last one is only used if you turn renaming on).
  2. Dans n'importe quel salon, tape /gkeep-setup/gkeep-setup. Une fenêtre s'ouvre : Étape 1 sur 3. Écris le nom exact de la guilde en jeu, majuscules et accents compris, puis valide.In any channel, type /gkeep-setup/gkeep-setup. A window opens: Step 1 of 3. Type the exact in-game guild name, capitals and accents included, then submit.
  3. Étape 2 sur 3 · Options : choisis « Ne pas toucher aux pseudos » (par défaut) ou « Renommer avec le personnage principal », et, si tu veux, un salon où le bot annonce chaque nouvelle commande de craft. Clique ContinuerContinue (ou Modifier le nomChange the name pour corriger l'étape 1).Step 2 of 3 · Options: pick "Leave nicknames alone" (the default) or "Rename after the main character", and, if you like, a channel where the bot announces every new craft order. Click ContinuerContinue (or Modifier le nomChange the name to fix step 1).
  4. Étape 3 sur 3 · Récapitulatif : vérifie le nom, les pseudos et le salon. Un encadré « À vérifier » signale un droit manquant au bot. Clique Créer ma guildeCreate my guild.Step 3 of 3 · Summary: check the name, nicknames and channel. A "Check this" box flags a permission the bot is missing. Click Créer ma guildeCreate my guild.
  5. Le bot répond « ta guilde est prête » avec le lien d'installation. Clique Annoncer dans ce salonAnnounce in this channel pour le publier aux membres, ou Ouvrir la pageOpen the page pour le voir.The bot replies "your guild is ready" with the install link. Click Annoncer dans ce salonAnnounce in this channel to post it for members, or Ouvrir la pageOpen the page to see it.

AttentionWatch out

Le nom doit être exactement celui du jeu : seuls les personnages de cette guilde entrent dans l'annuaire. Et le lien d'installation donne accès aux données de la guilde : ne le publie pas hors de ton serveur.The name must match the game exactly: only that guild's characters enter the directory. And the install link grants access to the guild's data: don't post it outside your server.

AstuceTip

Pour le renommage des pseudos, donne au bot le droit « Gérer les pseudos » et place son rôle au-dessus de ceux des membres. Le propriétaire du serveur ne peut jamais être renommé par un bot.For nickname renaming, give the bot the "Manage Nicknames" permission and put its role above members' roles. A bot can never rename the server owner.

#Admin : gérer la guilde ensuiteAdmin: manage the guild later

Admin « Gérer le serveur »Admin (“Manage Server”)

Relance /gkeep-setup/gkeep-setup : sur un serveur déjà inscrit, il ouvre le panneau de gestion, avec le lien d'installation actuel, le nombre de personnages et de membres, et :Run /gkeep-setup/gkeep-setup again: on a server that's already set up it opens the management panel, with the current install link, character and member counts, and:

  • un menu pour changer le salon des annonces de commandes (vide = aucune annonce) ;a menu to change the order announcement channel (empty = no announcements);
  • Renommer les pseudosRename nicknames ou Ne plus renommer les pseudosStop renaming nicknames ;Renommer les pseudosRename nicknames or Ne plus renommer les pseudosStop renaming nicknames;
  • Nouveau lien d'installationNew install link : à confirmer par Oui, nouveau lienYes, new link. L'ancien lien et les packs déjà installés cessent de fonctionner ; chaque joueur retélécharge le pack ;Nouveau lien d'installationNew install link: confirm with Oui, nouveau lienYes, new link. The old link and packs already installed stop working; every player downloads the pack again;
  • Supprimer la guildeDelete the guild : à confirmer par Oui, tout supprimerYes, delete everything. L'annuaire, les commandes et les liens Discord sont effacés, sans retour possible.Supprimer la guildeDelete the guild: confirm with Oui, tout supprimerYes, delete everything. The directory, orders and Discord links are erased, for good.

Le salon des annonces de la guilde (module Communication) se règle à part : /gkeep annonce salon/gkeep announce channel, réservé lui aussi au droit « Gérer le serveur ». Voir Communication.The guild announcement channel (Communication module) is set separately: /gkeep annonce salon/gkeep announce channel, also limited to the "Manage Server" permission. #Joueur : installer le pack de la guildePlayer: install the guild pack

Tout membreAny member

Trois façons, de la plus simple à la plus manuelle. Le pack est recommandé : il installe l'addon et le tient à jour.Three ways, from simplest to most manual. The pack is recommended: it installs the addon and keeps it up to date.

WindowsTutoriel : installer le packTutorial: install the pack

  1. Ouvre le lien d'installation partagé par ton officier (ou colle son code dans le champ « Ta guilde t'a donné un code ? » en bas de l'accueil).Open the install link your officer shared (or paste its code into the "Your guild gave you a code?" field at the bottom of the home page).
  2. Clique Télécharger le packDownload the pack, puis dézippe-le où tu veux (le dossier Guildkeep peut rester dans Téléchargements).Click Télécharger le packDownload the pack, then unzip it anywhere (the Guildkeep folder can stay in Downloads).
  3. Lance GuildkeepCompanion. Si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires », puis « Exécuter quand même ». Une seule fois.Run GuildkeepCompanion. If Windows shows "Windows protected your PC": "More info", then "Run anyway". Once only.
  4. Le compagnon trouve World of Warcraft, y installe l'addon, puis se relance tout seul à chaque démarrage de Windows. Il ne lance jamais le jeu.The companion finds World of Warcraft, installs the addon in it, then restarts by itself every time Windows starts. It never launches the game.
  5. En jeu : /gkeep, ou l'onglet Guildkeep de la fenêtre de guilde. Si WoW était ouvert pendant l'installation, relance le jeu.In game: /gkeep, or the Guildkeep tab in the guild window. If WoW was open during the install, restart the game.

MacTutoriel : installer le pack sur MacTutorial: install the pack on Mac

  1. Télécharge le pack : Safari le dézippe tout seul dans Téléchargements.Download the pack: Safari unzips it by itself into Downloads.
  2. Le compagnon n'est pas notarisé par Apple : macOS le refuse la première fois. Lance-le, puis Réglages Système, Confidentialité et sécurité, tout en bas : « Ouvrir quand même ». Ou dans le Terminal : xattr -dr com.apple.quarantine ~/Downloads/GuildkeepThe companion isn't notarized by Apple, so macOS refuses it the first time. Run it, then System Settings, Privacy & Security, at the bottom: "Open Anyway". Or in Terminal: xattr -dr com.apple.quarantine ~/Downloads/Guildkeep
  3. Lance-le dans le Terminal : cd ~/Downloads/Guildkeep && ./GuildkeepCompanion, et laisse-le tourner pendant que tu joues.Run it in Terminal: cd ~/Downloads/Guildkeep && ./GuildkeepCompanion, and leave it running while you play.

LinuxTutoriel : installer le pack sur LinuxTutorial: install the pack on Linux

  1. Dézippe, puis chmod +x GuildkeepCompanion && ./GuildkeepCompanion. Les installations Steam/Proton et Lutris sont détectées.Unzip, then chmod +x GuildkeepCompanion && ./GuildkeepCompanion. Steam/Proton and Lutris installs are detected.
  2. Laisse-le tourner pendant que tu joues : un terminal, tmux ou un service systemd utilisateur.Keep it running while you play: a terminal, tmux or a systemd user service.

Pas d'app compagnon possible (PC du travail, refus d'installer) ? L'addon seul fonctionne avec une chaîne de texte à copier-coller : voir le canal manuel. Il faut alors installer l'addon toi-même (CurseForge, ou le dossier Guildkeep du pack copié dans Interface/AddOns).No companion app possible (work PC, won't install)? The addon alone works with a copy-and-paste text string: see the manual channel. You then install the addon yourself (CurseForge, or the pack's Guildkeep folder copied into Interface/AddOns).

AstuceTip

Des personnages dans une autre guilde ? Lance aussi le pack de cette guilde : un seul compagnon tourne et les synchronise toutes, chaque personnage ne voyant que sa propre guilde.Characters in another guild? Run that guild's pack too: a single companion runs and syncs them all, and each character only sees its own guild.

Activer ou couper un moduleTurn a module on or off

Chacun des huit modules s'active séparément, pour ton compte. Un module coupé ne relève rien, n'envoie rien et n'affiche pas son onglet ; ses données restent.Each of the eight modules is turned on separately, for your account. A module that's off records nothing, sends nothing and hides its tab; its data stays.

En jeuIn gameTutoriel : choisir ses modulesTutorial: choose your modules

  2. Coche ou décoche les modules : Métiers, Membres, Artisanat, Événements, Soirée de raid, Présence et butin, Quêtes, Communication.Tick or untick the modules: MétiersMétiers (Professions), MembresMembres (Members), ArtisanatArtisanat (Crafting), ÉvénementsÉvénements (Events), Soirée de raidSoirée de raid (Raid night), Présence et butinPrésence et butin (Attendance and loot), QuêtesQuêtes (Quests), Communication.
  3. Clique Recharger l'interfaceRecharger l'interface (Reload UI) : le changement prend effet au rechargement.Click Recharger l'interfaceRecharger l'interface (Reload UI): the change applies on reload.

Au clavier : /gkeep modules affiche l'état de chacun ; /gkeep modules quests off (ou on) change un module, par son identifiant (professions, members, craft, events, raid, attendance, quests, communication) ou son nom ; puis /reload.By keyboard: /gkeep modules shows each one's state; /gkeep modules quests off (or on) changes a module, by its id (professions, members, craft, events, raid, attendance, quests, communication) or its name; then /reload.

Bon à savoirGood to know

Les messages de connexionLogin messages

À chaque connexion ou /reload, Guildkeep écrit dans le chat une ligne par module :At every login or /reload, Guildkeep writes one chat line per module:

  • module Métiers chargé : tout va bien ;module Métiers chargé (loaded): all good;
  • module Quêtes désactivé : tu l'as coupé (ou il lui manque un module dont il dépend) ;module Quêtes désactivé (disabled): you turned it off (or a module it needs is missing);

#Relier ton compte DiscordLink your Discord account

Toi seulOnly you

Relier ton personnage à ton compte Discord te permet de t'inscrire, réserver, commander ou contribuer depuis Discord, et de recevoir les messages privés du bot (nouvelle commande, offre…).Linking your character to your Discord account lets you sign up, reserve, order or contribute from Discord, and get the bot's direct messages (new order, offer…).

DiscordTutoriel : lier ton personnageTutorial: link your character

  1. Tape /gkeep lier/gkeep link et, dans personnage, le nom complet de ton personnage tel qu'il est en jeu, prénom et nom (par exemple Maël Corvin).Type /gkeep lier/gkeep link and, in character, your character's full name as in game, first and last name (for example Maël Corvin).
  2. Le premier personnage lié devient ton principal. Pour en changer : /gkeep principal/gkeep main (la liste propose tes personnages liés).The first linked character becomes your main. To change it: /gkeep principal/gkeep main (the list suggests your linked characters).
  3. Si ta guilde a activé le renommage, ton pseudo Discord devient le nom de ton principal. Pour le changer, passe par /gkeep principal/gkeep main plutôt que par les réglages Discord : le bot le réapplique.If your guild turned renaming on, your Discord nickname becomes your main's name. To change it, use /gkeep principal/gkeep main rather than Discord settings: the bot reapplies it.

AstuceTip

Avec ton token personnel dans le compagnon, tes personnages relevés en jeu sont reliés à ton compte automatiquement.With your personal token in the companion, your characters scanned in game are linked to your account automatically.

Comment on devient officierHow you become an officer

  • En jeu, l'addon lit ton rang : maître de guilde, rang juste en dessous, ou statut d'officier donné par le jeu. Rien à régler.In game, the addon reads your rank: guild master, the rank just below, or officer status given by the game. Nothing to set.
  • Sur Discord, tu es officier si l'un de tes personnages liés a ce rang relevé en jeu, ou si tu as le droit « Gérer le serveur ».On Discord, you're an officer if one of your linked characters has that rank as recorded in game, or if you have the "Manage Server" permission.

AttentionWatch out

Le rang d'officier n'est enregistré sur le serveur que s'il arrive par ton token personnel (/gkeep token/gkeep token, voir le compagnon). Le pack seul (token de guilde) ou une chaîne collée avec /gkeep importer/gkeep import ne suffisent pas : sinon n'importe qui pourrait se déclarer officier.The officer rank is only recorded on the server when it comes through your personal token (/gkeep token/gkeep token, see the companion). The pack alone (guild token) or a string pasted with /gkeep importer/gkeep import isn't enough: otherwise anyone could claim to be an officer.
